BANKFLOW - DSA MICRO PROJECT WEBSITE

1. Extract the ZIP.
2. Double-click index.html to open it in Chrome or Edge.
3. Create two accounts, then queue deposits, withdrawals, and transfers.
4. Click Process Next or Process All to process transactions in FIFO order.
5. Search accounts, sort history, and view most recent transactions first.

This is a front-end educational simulation using browser localStorage. It is not connected to the C program or any real bank. For a real multi-user system, a secure backend and database are needed.
